# 📦 Content Matrix Archive

播客/音视频内容矩阵存档，由 [podcast-content-machine](https://github.com/qingmozhu2016-cell/podcast-content-machine) Skill 自动生成并推送。

## 目录结构

每个视频/音频会生成一个以标题命名的文件夹，包含：

| 文件 | 说明 |
|------|------|
| `transcript_full.txt` | 带说话人标签的逐字稿 |
| `blog_post.md` | 中英双语博客摘要 |
| `social_quotes.md` | 5条社交媒体金句 |
| `card-cover.png` | 封面卡片 |
| `card-skill*.png` | 内容卡片 |
| `card-summary.png` | 总结卡片 |
