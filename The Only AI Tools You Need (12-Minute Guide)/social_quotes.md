# 5 Social Media Gold Quotes / 5条社交媒体金句
Source: Jeff Su — "The Only AI Tools You Need (12-Minute Guide)"

---

### Quote 1 / 金句一

🇬🇧 "ChatGPT doesn't decide which instructions matter — it just follows them. If a task has a lot of moving parts and getting one wrong breaks the whole thing, start with ChatGPT."

🇨🇳 "ChatGPT不会自作主张决定哪条指令重要——它只管执行。如果一个任务环节很多、错一步就全盘崩溃，首选ChatGPT。"

---

### Quote 2 / 金句二

🇬🇧 "Gemini is the only tool that can synthesize a video recording, a 20-slide deck, and a whiteboard photo in one go. When the task involves mixed media, the trade-off is obviously worth it."

🇨🇳 "Gemini是唯一能同时处理视频录像、20页PPT和白板照片的工具。当任务涉及混合媒体时，选它完全值得。"

---

### Quote 3 / 金句三

🇬🇧 "Claude wrote a script in Go that worked on the first try — and I don't even know what Go is. Anything that requires generating working code tends to favor Claude."

🇨🇳 "Claude用Go语言写了一个脚本，一次就跑通了——而我连Go是什么都不知道。凡是需要生成可运行代码的任务，Claude都占优。"

---

### Quote 4 / 金句四

🇬🇧 "Perplexity is built for fetching, not reasoning. Think of it as a search scalpel — you need a specific fact, and you need it now."

🇨🇳 "Perplexity是为'取信息'而生的，不是为'做推理'。把它当成搜索手术刀——你需要一个具体事实，而且现在就要。"

---

### Quote 5 / 金句五

🇬🇧 "We should never use tools just for the sake of using tools. We should only add them to our toolkit when they solve an actual problem we have."

🇨🇳 "永远不要为了用工具而用工具。只有当一个工具能解决你实际存在的问题时，才值得加入你的工具箱。"
